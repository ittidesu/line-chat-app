# LINE Chat App

LINE風チャットアプリケーション

## 機能

- ユーザーのログイン・サインアップ
- プロフィール設定
- ワンツーワンチャット
- グループチャット
- 既読表示
- メッセージ編集・削除
- テーマカスタマイズ
- 友達追加機能
- 管理者機能（ユーザー管理、お知らせ配信など）
- ブロック・削除機能
- ユーザー検索

## セットアップ

```bash
npm install
npm start
```
